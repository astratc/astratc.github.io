# Crypto Launch Copy Kit (v1, Astra Trading Company)
25 fill-in-the-blank templates for token, protocol and SaaS launches. Replace every {BRACKET}. No hype words, no price promises: these templates are written to pass exchange, X and Mycelium-style disclosure rules.

## A. X / Bluesky threads
1. **Launch thread (8 posts)**
   1/ {PROJECT} is live. {ONE-LINE WHAT IT DOES} for {WHO}.
   2/ The problem: {PAIN, with one concrete number or example}.
   3/ What we built: {MECHANISM in plain words}.
   4/ How it works in 3 steps: 1) {STEP} 2) {STEP} 3) {STEP}
   5/ What's different: {DIFFERENTIATOR vs the obvious alternative}.
   6/ Safety: {AUDIT / OPEN SOURCE / LIMITS}. Risks: {MAIN RISK, honestly}.
   7/ Try it: {LINK}. Docs: {DOCS LINK}.
   8/ We'd love feedback on {SPECIFIC QUESTION}. Reply or open an issue.
2. **Feature update thread (5 posts)**: Shipped: {FEATURE} / Why: {USER REQUEST} / Before vs after: {DELTA} / How to use: {STEPS} / Next: {ROADMAP ITEM}.
3. **Metrics thread**: {PERIOD} in numbers: {METRIC 1}, {METRIC 2}, {METRIC 3}. What moved them: {CAUSE}. What didn't work: {HONEST MISS}. Next: {GOAL}.
4. **Explainer thread**: "{CONCEPT} in 6 posts, no jargon." Analogy -> mechanism -> example -> risk -> where {PROJECT} fits -> link.
5. **Incident/post-mortem thread**: What happened ({TIME, UTC}) / Impact ({WHO, HOW MUCH}) / Root cause / Fix shipped / What we change / Funds status: {SAFE/AFFECTED + plan}.

## B. Launch posts and announcements
6. **Blog launch post**: H1 {PROJECT}: {BENEFIT}. Sections: The problem / Our approach / How it works / Security & risks / Roadmap / Get started.
7. **Partnership announcement**: {A} x {B}: {WHAT USERS GET}. Why together / What changes today / Timeline / Links.
8. **Listing announcement**: {TOKEN} is now available on {VENUE}. Pairs: {PAIRS}. Contract: {ADDRESS} (verify on {EXPLORER}). Not investment advice.
9. **Grant/Funding announcement**: {AMOUNT} from {FUNDER} to build {DELIVERABLE} by {DATE}. Milestones: {M1, M2, M3}.
10. **Changelog entry**: ### {VERSION} ({DATE}) Added / Changed / Fixed / Security.

## C. Landing page
11. **Hero**: Headline: {OUTCOME} without {PAIN}. Sub: {PROJECT} lets {WHO} {DO WHAT} in {TIME/STEPS}. CTA: {VERB} {OBJECT}.
12. **3 benefit blocks**: {BENEFIT} - {PROOF}. (x3)
13. **How it works (3 steps)**.
14. **FAQ (6 Qs)**: Is it audited? Fees? Custody? Supported chains? Risks? Support?
15. **Social proof row**: "{QUOTE}" - {ROLE, PROJECT}. Only real quotes.
16. **Final CTA**: Ready to {OUTCOME}? {BUTTON}. {REASSURANCE: no signup / open source / non-custodial}.

## D. Docs
17. **README skeleton**: What / Why / Quickstart (3 commands) / Config table / Examples / Troubleshooting / License.
18. **Quickstart page**: Prerequisites / Install / First call / Expected output / Next steps.
19. **Error reference row**: `{ERROR}` - Meaning: {MEANING}. Funds: {SAFE/UNKNOWN}. Action: {RETRY/INSPECT/CONTACT}.
20. **Integration guide intro**: "By the end you will have {RESULT} running against {NETWORK}. Time: {MIN} minutes."

## E. Community, email, outreach
21. **Newsletter (weekly)**: Subject: {PROJECT} weekly: {HEADLINE}. Sections: Shipped / Numbers / Community spotlight / Next week.
22. **Discord/Telegram announcement**: {EMOJI-FREE TITLE}. What / When ({UTC}) / Action needed: {NONE or STEPS} / Questions: {CHANNEL}.
23. **AMA prep**: 10 likely questions with 2-sentence answers: tokenomics, unlocks, audits, team, revenue, roadmap, risks, competitors, why now, how to help.
24. **Cold intro to a partner**: Hi {NAME}, {PROJECT} does {X}. Your users {PAIN}. Proposal: {SMALL CONCRETE PILOT}. 15 min this week? {SIGNATURE}
25. **Bounty/Quest brief**: Task / Deliverable / Acceptance criteria / Reward / Deadline (UTC) / Disclosure rules.

## Style rules
- One claim, one proof. Numbers beat adjectives.
- Always state risks and that nothing is financial advice.
- Disclose paid or AI-assisted content where platforms require it.
- Use UTC for times; link contract addresses to an explorer.
